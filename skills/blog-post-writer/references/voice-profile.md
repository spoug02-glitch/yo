# 문체 프로파일

출처: 사용자 네이버 블로그 17편 (2026.07.09 ~ 07.28), 총 1,280줄 분석.
글을 쓰기 전 이 파일을 읽고, 아래 규칙을 본문에 그대로 적용한다.

---

## 0. 먼저 — 글 종류에 따라 어투가 갈린다

사용자 확인 결과, 어투는 두 갈래다. **글 종류를 먼저 판단하고 어투를 고른다.**

| 글 종류 | 어투 | 예 |
|---|---|---|
| 경험담·개발기·일상·후기 | **평서체(`~다`)** | 배포기, 틔운 미니, 운전면허 후기 |
| 정보성 안내·정리글 | **존댓말** | 자격증 가이드, 제도 정리 |

애매하면 이렇게 가른다. **"내가 겪은 일"이 뼈대면 평서체, "독자가 알아야 할 정보"가 뼈대면 존댓말.**

아래 2~9번의 리듬·구조 습관은 **어투와 무관하게 항상 적용**한다. 존댓말로 쓰더라도 짧은 줄, 구어 접속어, 결론 먼저는 그대로 가져간다.

---

## 1. 평서체로 쓸 때

블로그 원문 기준 평서체 종결 523회, 존댓말 11회다. 경험담에서는 평서체가 기본값이다.

- 맞음: 짰다 / 구매했다 / 올렸다 / 없었다 / 그런 셈이다 / 다르다는 것
- 틀림: 짰습니다 / 구매했어요

존댓말이 예외로 나오는 자리는 독자에게 직접 부탁할 때뿐이다.
*"같은 틔운 미니 쓰는 분들 중에 비슷한 증상 겪은 분 있으면 댓글로 알려주시면 감사하겠다."*

## 2. 줄바꿈 — 한 문장이 한 줄이다

- 줄 길이 **중앙값 23자**, 평균 26.9자
- 전체 줄의 **64.8%가 30자 이하**

긴 문장을 쓰지 않는다. 쉼표로 이어붙일 자리에서 그냥 끊어서 다음 줄로 내린다.

이렇게 쓴다.

```
기획은 하루 전날 밤에 끝났다. 이제 만들 차례였다.

바이브 코딩으로 짰다. 투표 페이지 하나, 버튼 두 개, 실시간으로 쌓이는 표 수. 복잡한 기능은 없었다.

도메인도 그럴듯하게 하고 싶었다. butterbread.kr을 구매했다.
```

이렇게 쓰지 않는다.

```
기획은 하루 전날 밤에 끝났고, 이제 만들 차례였기 때문에 바이브 코딩으로 투표 페이지 하나와
버튼 두 개, 실시간으로 쌓이는 표 수를 구현했으며, 도메인도 그럴듯하게 하고 싶어서
butterbread.kr을 구매했다.
```

## 3. 시점 — 1인칭 경험담

"나는", "내가", "~해봤다"로 쓴다. 가끔 "필자"도 쓰지만 드물다.

정보 전달 글에서도 관찰자가 아니라 **직접 해본 사람**의 자리에서 쓴다.

- *"그래서 감이 아니라 데이터로 정리해봤다. 한국관광 데이터랩의 강릉시 관광 데이터를 직접 받아서."*
- *"원인 찾아보니 네이버 블로그 검색 API를 따옴표로 감싸서 정확매칭으로 보내고 있었다."*

---

## 4. 접속어 — 구어 쪽을 쓴다

문단 첫머리 빈도.

| 접속어 | 횟수 |
|---|---|
| 그래서 | 25 |
| 근데 | 18 |
| 그리고 | 11 |
| 그런데 | 9 |
| 대신 | 5 |
| 결론부터 | 4 |
| 문제는 | 3 |
| 일단 / 정리하면 / 결국 / 다만 | 각 3 |

**"근데"를 "그런데"보다 자주 쓴다.** 딱딱한 "따라서", "그러므로", "또한"은 쓰지 않는다.

"문제는 그다음이었다." 같은 전환 문장을 즐겨 쓴다.

---

## 5. 구조 습관

**결론 먼저.** *"결론부터 말하자면 —"* 로 시작해 핵심을 먼저 던지고 근거를 뒤에 푼다.

**번호로 예고.** 본론 앞에서 다룰 내용을 ①②③으로 미리 나열한다.

```
그래서 이 글에선 데이터로 세 가지를 풀어본다.

① 세대별 인기 관광지 — 20대 vs 60대
② 요즘 뜨는 곳 — 성장율 급등 스팟
③ 우리 가족 구성엔 어디가 맞을까
```

**독자에게 말 건다.** 물음표 문장 35회.
*"차이가 보이나?"*, *"보면 알겠지만"*, *"근데 진짜 재밌는 건 여기."*

**시리즈물.** 앞뒤 편 링크를 본문 위아래에 건다. 제목 끝에 `①`, `- 3편` 같은 표시를 단다.

**"총총." 마무리는 쓰지 않는다.** 원문에 14회 등장하지만 사용자가 사용하지 않기로 했다.

## 6. 감정과 실패를 숨기지 않는다

이 블로그의 핵심 매력이다. 잘된 것보다 안 된 것을 더 자세히 쓴다.

- *"올려놓고 나서는 댓글을 하나도 보지 않았다. 반응이 무서웠다."*
- *"지금도 그 순간이 너무 무서워서, 아직도 확인 못 하고 있다."*
- *"정작 나이 때문에 그 채널들에 발도 못 붙이는 상황이 웃기면서도 당황스러웠다."*
- *"AI API 붙이면 좋을 줄 알았는데, 오히려 안 붙였다"*

매끈한 성공담으로 다듬지 말 것. 삽질 과정과 그때의 기분을 그대로 남긴다.

---

## 7. 구어 표현 — 쓰지 않는다

원문에는 ㅋㅋ(5회), ㅡㅡ;(8회), ㅇㅇ(1회)가 여행·일상 글에 섞여 있다. **하지만 사용자가 전부 빼기로 했다.**

- `ㅋㅋ` — 쓰지 않는다
- `ㅡㅡ`, `;;`, `ㅇㅇ` — 쓰지 않는다. 되도록 줄인다

말줄임표 `…`(42회)는 예외로 남긴다. 여운을 주는 자리에 쓰면 된다.
*"덕분에 정말 잘 돌아갔는데……."*

구어감은 자모 표현 대신 **어휘와 문장 리듬**으로 낸다. "근데"를 쓰고, 문장을 짧게 끊고, 독자에게 질문을 던지는 방식이다.

---

## 8. 출처는 항상 붙인다

이미 몸에 밴 습관이다. 본문에 10회 등장.

- *"모든 자료의 출처는 한국관광 데이터랩 / 인기 관광지는 2025.07~2026.06, 뜨는 곳은 2026.06 기준"*
- *"경포해변 전경, 출처 : 카카오맵"*

이미지 캡션에도 `출처 : ○○` 형식으로 단다. 수치를 쓰면 기준 기간까지 밝힌다.

## 9. 제목 패턴

실제 사용 제목에서 뽑은 형태다.

| 유형 | 예시 |
|---|---|
| ~하다가 ~한 이야기 | LG 틔운 미니로 해바라기 키우다가, 꽃봉오리 맺힌 뒤에 병든 이야기 |
| ~해본 후기 | 네이버 블로그 비싼 강의 없이 AI 분석 프롬프트 만들고 직접 돌려본 후기 |
| A vs B | 강릉 가볼만한 곳, 부모님이랑 vs 친구랑 다르다 |
| 반전형 | AI API 붙이면 좋을 줄 알았는데, 오히려 안 붙였다 |
| 본제목 — 부제 | 나만의 블랙키위 만들기 — 크롤링 대신 공식 API로 키워드 트렌드 뽑아본 기록 |
| 시리즈 번호 | ~ - 내 블로그 분석기 1 / ② / 3편 |

공통점은 **결과를 제목에서 미리 흘린다**는 점이다. "~하는 방법" 같은 무미건조한 형태는 거의 없다.

## 10. 확정된 사항

- 어투는 글 종류로 가른다 (0번)
- "총총." 마무리 — **사용 안 함**
- ㅋㅋ / ㅡㅡ / ;; / ㅇㅇ — **사용 안 함**
- 말줄임표 `…` — 사용 가능
- AICE 자격증 가이드 계열은 **존댓말**로 확정
