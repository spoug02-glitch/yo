# 문체 예시 모음

SKILL.md 3장 문체 지침의 실제 적용 예시. 집필 중 감이 안 잡힐 때 참고할 것.

---

## 1. 인용구 → 기울임 전환

### 원문 인용

**전 (블록인용)**
```
> AI Certificate for Everyone(AICE) 종목의 Junior, Basic, Professional 등급은
> 민간자격으로 국가로부터 인정받은 공인자격이 아닙니다.
```

**후 (기울임)**
```
공식 홈페이지의 소비자 알림사항은 이렇게 못 박고 있습니다.
*"AI Certificate for Everyone(AICE) 종목의 Junior, Basic, Professional 등급은
민간자격으로 국가로부터 인정받은 공인자격이 아닙니다."*
```

### 주의 박스

**전**
```
> ⚠️ 오프라인 접수 마감이 온라인보다 약 1주 빠릅니다.
```

**후**
```
**오프라인 접수 마감이 온라인보다 약 일주일 빠릅니다.** 3·4·5회차에 오프라인으로
응시할 생각이라면 마감일을 따로 적어두세요.
```

### 참고 문단

**전**
```
> 📌 이 기간은 특정 블로그의 안내이며 공식 기준이 아닙니다.
```

**후**
```
다만 이 기간은 특정 블로그가 제시한 값이고, 공식 기준이 아닙니다. 파이썬을
얼마나 다뤄봤느냐에 따라 편차가 큽니다.
```

## 2. 표 → 문장 풀어쓰기

3개 이하 항목이거나 설명이 한 줄이면 문장이 낫다.

**전 (표)**

| 시점 | 환불 |
|---|---|
| 접수 기간 중 | 100% |
| 접수 종료 후 ~ 시험 5일 전 | 50% |
| 시험 4일 전부터 | 불가 |

**후 (문장)**

접수 기간 안에 취소하면 전액 돌려받습니다. 기간이 끝난 뒤에는 시험 5일 전까지 절반만 환불되고, 나흘 전부터는 취소 자체가 막힙니다.

날짜를 잘못 잡으면 8만 원이 그대로 날아간다는 뜻입니다.

---

**전 (표)**

| 등급 | 도구 |
|---|---|
| Junior, Basic | AIDU |
| Associate, Professional | Jupyter / ANACONDA·Colab |

**후 (문장)**

도구는 등급에 따라 완전히 갈립니다. Junior와 Basic은 코딩 없이 쓰는 AIDU를 쓰고, 이건 공식 홈페이지에서 무료로 받을 수 있습니다. Associate 위로는 파이썬이고, 시험장은 주피터 환경입니다. 연습은 ANACONDA를 깔거나 설치가 귀찮으면 Colab으로 하면 됩니다.

## 3. 관찰 한 줄 넣기

정보 문단 뒤에 붙이는 짧은 판단. 톤은 평서체로 떨어뜨려도 좋다.

**출제범위 충돌 설명 뒤**
> 총 문항수와 총점은 양쪽이 같고, 분야 구분과 배점 배분만 다릅니다. 학습 범위 자체가 뒤집히는 건 아닙니다.

**국가공인 범위 설명 뒤**
> 이 구분을 모르고 "국가공인 AI 자격증 땄다"고 쓰면 서류에서 곤란해질 수 있습니다.

**합격률 문단 뒤**
> 결국 준비 강도를 정하는 근거로는 못 씁니다.

**오프라인 마감일 뒤**
> 여기서 생기는 일주일 차이가 생각보다 큽니다.

**우대 사례 뒤**
> 다만 이건 전부 보도 시점 기준이고, 채용 공고는 해마다 바뀝니다.

## 4. 짧은 문단 배치

결론 앞뒤에 한두 문장 문단을 둔다.

```
...(긴 설명 문단)...

즉 Basic은 국가공인이 아닙니다.

"국가공인 AI 자격증"이라는 표현은 Associate 하나에만 붙일 수 있습니다.
Basic을 그렇게 소개한 자료가 꽤 많으니 걸러서 보세요.
```
